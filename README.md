Exploratory Data Analysis (EDA) and Visualization with FireDucks vs Pandas 🚀📊
This project is all about comparing two powerful Python libraries — FireDucks and Pandas — when it comes to Exploratory Data Analysis (EDA) and data visualization on large datasets 🌟.

We created detailed benchmarks to compare common EDA operations and visualization tasks to see which library performs faster and more efficiently ⚡.

✨ What’s Inside?

Filtering Rows: Compare how quickly FireDucks and Pandas filter large datasets 📈.

GroupBy Operations: Evaluate the performance of grouping and aggregating data with both libraries 📊.

Data Merging: See how efficiently FireDucks and Pandas merge datasets 🤝.

Visualization Preparation: Benchmark the time it takes to prepare data for visualization 🎨.

Visualization Examples: Explore plots created with Matplotlib and Seaborn to compare visualization efficiency 📈.

Simple, clean & realistic operations you’ll find in any data engineering or analytics workflow 💻.
